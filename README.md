# 交易驾驶舱

本仓库以桌面版为唯一生产入口，保留早期网页作为冻结的设计参考：

- `desktop/`：当前主产品。Electron 桌面应用，把用户自己的 TradingView 网页会话、长桥真实持仓与本地交易 Agent 放在同一窗口。
- `app/`：早期托管网页原型。它不能透传 TradingView 的个人登录会话，不与桌面能力同步，也不作为真实账户操作入口；仅通过 `prototype:*` 命令运行。

## 桌面版快速开始

环境要求：Node.js `>=22.13.0`、macOS。

```bash
npm --prefix desktop install
npm run desktop:test
npm run desktop:dev
```

根目录 `dev/build/start/test` 也指向桌面版。发布统一运行 `npm run verify:release -- --target mac`：包含单元、隔离桌面交互、打包依赖及产物完整性检查，成功后生成带源码、依赖、Skill 与产物哈希的验证清单，不自动安装或覆盖正在运行的应用。

最近完成完整离线发布门禁的版本为 **0.24.6**（1117 项测试、4 组源码与 4 组包内交互、15 项门禁通过），没有自动安装或替换用户应用。0.24.5 是复审后被后续修复替代的中间构建，不推荐安装。可靠性收敛进展见 [实施台账](desktop/audits/STABILITY_IMPLEMENTATION.md) 和 [本轮复核与整改](desktop/audits/STABILITY_FOLLOWUP_2026-09-18.md)。旧案例迁移与复盘主路径已统一；IBKR 历史、完整收益账本及真实服务/连续多日验收仍未完成。启用历史分段后勿用旧版直接打开同一数据目录；源码回退不等于数据格式可直接降级。

首次启动后：

1. 在中间 TradingView 区域登录。该区域使用独立的 `persist:tradingview` 本机会话，保留个人 Layout、画线、指标与 Cookie。
2. 点击右上角“连接长桥”。系统浏览器会打开 Longbridge OAuth，只请求账户/持仓读取（scope 6）与订单/成交历史查询（scope 10）；凭证通过 macOS Keychain 支持的 Electron `safeStorage` 加密保存。
3. 选择真实持仓，并按需点击“同步标的到 TV”。这个动作只导航 TradingView 页面，不读取或注入 TradingView DOM。
4. 在右侧选择“当前持仓 / 候选买入 / 全部组合”并运行持久 Codex Agent；候选标的不必已经持有，全组合模式会检查全部真实仓位但不会逐只拉 K 线。
5. 需要分开讨论时点击“新建”创建独立 Codex 会话；点击“本机对话”会直接打开原 thread、显示原内容并继续。不同会话可同时运行，各自显示状态；项目工具共享而聊天上下文隔离。输入 `/`、`$` 或 `@` 仍可联想命令、Skills、Apps 与 MCP 工具。
6. 两条分隔线可拖拽，左右栏也可隐藏；TradingView 只重算原生视口，不会被 CSS 缩放或拉伸。
7. 切换到“复盘实验室”后，可选择自然月或单标的订单。轻量路径先用三句话记录“事后回忆的当时判断 / 本次感悟 / 从当前时点生效的未来预判”，确认后才原子建立周期、关联真实订单并补齐同单成交；需要验证事前判断时，再选择严谨模式封存证据并运行盲态 / 结果两阶段复盘。

## 只读边界

- Longbridge 固定使用官方全球 `.com/v2`，不根据 macOS 地区猜测账户区域，也不自动回退到香港或中国大陆节点。OAuth、MCP 与 ECB 参考汇率请求统一使用 Electron/Chromium 网络栈，自动继承 macOS 系统代理。
- OAuth 精确请求 `scope=6 10`（账户/持仓读取 + 订单/成交历史查询）；不会请求 `scope=11`（下单、改单、撤单）。从旧的 scope 6 版本升级时会要求一次新的只读授权。
- 主进程必需查询白名单为 `account_balance`、`stock_positions`、`quote`、`option_quote`、`candlesticks` 和 `exchange_rate`；另可选允许 `history_orders`、`history_executions`、`today_orders`、`today_executions` 与 `order_detail` 供复盘使用。所有订单接口均为查询，写操作仍被拒绝。
- 客户端拒绝调用白名单之外的所有工具；若缺少任一必需查询工具或出现真实订单工具，则拒绝建立连接。
- Renderer 不接触 MCP Client、OAuth Token、Node.js 或任意通用工具调用入口。
- Codex App Server 是唯一的 Agent harness，统一负责线程、历史、Skills/MCP/Apps、工具事件、取消和最终结果收集。EMA、Fib、仓位与风险引擎只是只读证据工具，不维护第二套会话或 Agent 状态。长桥桥接层不暴露提交、修改或取消订单的能力。
- Codex 仍可使用全部正常分析能力；应用会在 `thread/start` / `thread/resume` 的配置层精确禁用已识别 Longbridge MCP 的真实下单、改单、撤单、平仓、行权和 DCA 写工具，并禁用 Apps 的破坏性动作，同时保留行情、持仓、订单查询、研究类 Apps、Skills、网页、Shell 和文件能力。若校验后仍发现交易写工具，本轮不会启动。
- Agent 终态采用“通知快速返回 + 持久 turn 状态对账”双路径；漏掉完成通知时会从同一个 App Server 线程回收结果，最近完成结果也会加密保存供界面重载恢复。

## Agent 分析口径

- 技术框架采用开放证据栈：价格/成交量、趋势与动量、相对强弱、板块同行、成本/筹码结构、AVWAP、波动率/期权与事件后价格反应可按适用性组合，LLM 负责权重与冲突判断。
- EMA 3 / 5 / 8 / 13 / 21、EMA 144 / 169 与 Fib 0.382 / 0.618 / 1 / 1.618 继续作为基础确定性证据，但不是每轮必选的主框架。本地自动 Fib 仅为 `AUTO / ADVISORY`；只有 LLM 明确采用并通过真实 K 线锚点复核后才参与计划。
- 行情计算：Longbridge 1D OHLCV、前复权、仅常规交易时段，默认请求 1000 根。正式 EMA 只使用已确认收盘日 K；当日形成中 K 线单列为 `PROVISIONAL`。EMA 使用 Close、SMA seed 和标准指数递推，EMA169 至少有 507 根已完成日 K 才标记成熟。
- 日线同时保留提供方时间戳与交易所本地交易日；长桥日线午夜戳按该本地日期解释，并结合对应市场收盘时间判断 `FORMING / CLOSED`，避免盘中日 K 污染正式 EMA/Fib。
- 持仓估值优先采用时间戳最新的常规/盘前/盘后/夜盘报价；组合 `quoteAsOf` 取所有已估值持仓中最旧的一项。
- 账户总额直接采用长桥 USD 口径；多币种持仓通过已规范方向并经 USD/HKD 合理性校验的汇率图换算。集中度使用 gross exposure，另保留 net exposure。
- 候选买入由 Codex 结合叙事/技术 Skills、开放证据栈与可用只读 MCP 独立提出 Stage、失效位、仓位和现金/融资决策，不再使用本地 Stage 1 或 2%/4% 预设。宿主把模型建议限制在两分钟新鲜快照、购买力、单仓/Top5/主题、毛暴露、风险预算、保证金和衍生品覆盖等硬边界内；组合 gross exposure 在 120% 预警、150%（1.5×）硬性封顶，融资必须显式选择 `margin_within_cap`；界面同时显示 `LLM PROPOSED` 与 `HOST ACCEPTED`。
- 输出：技术结构、组合权重、主题暴露、参考位静态组合影响、牛/基准/熊静态条件计划与证据链。计划不在后台监控。

## 复盘、测试与规则

- “复盘周期”支持四类样本：由所选订单直接生成的单标的交易区间、财报等催化剂前后、单一持仓从建立到退出的完整生命周期、自然月组合。纯技术交易不必硬套催化剂或财报类型。
- 默认轻量路径固定为“记录三段原话 → 关联券商事实 → AI 复盘”：选月份会扫描该纽约自然月的账户历史，但主分析只纳入真实成交及能证明已成交/部分成交的父订单；纯未成交、取消、拒绝、过期、等待中订单和不可核验成交只进入排除审计。单标的区间只由用户当前框选的 Buy / Sell 订单或逐笔成交定义，不会向前搜索历史首笔交易。选整张订单时展开该订单的已归档成交；只选某笔成交时，父订单仅用于补充方向、币种和审计，不会把兄弟成交偷偷升级为路径锚点。三段记录分别保留版本与时间语义，未来预判只从保存时点起生效，不会倒填为本次交易的事前计划。月度严谨预判可在尚无订单时提前建立。
- 轻量周期可以重新增删订单。旧案例保持只读，须先显式预览并迁移为周期，不再继续建设旧案例写入路径。修改周期订单会建立新的证据 revision、保留旧集合与旧 AI 输出，并将旧结果标为 stale；单标的交易区间会按新选择重新推导起止时间，必须用最新证据完整重跑。
- 事前判断、市场预期、计划动作、失效条件以及当时可得的基本面/技术面证据会封存成带时间戳和哈希的不可变版本。阶段一把初始计划和每个不可变检查点拆成各自的节点证据胶囊，券商事实与日线必须严格早于该节点自己的知识截止时间；阶段二只有在阶段一完成且周期真实结束后才能运行，并引用冻结的阶段一结论。
- 每次首次复盘或阶段分析都会创建新的持久 Codex 对话；在该复盘里继续提问会复用原对话与证据上下文。严谨模式的两个阶段以同一 `cycle_id` 关联，但不向阶段一泄露阶段二行情、结果、后见叙事或旧聊天内容；直接事后复盘固定标为 retrospective，没有伪造的 knowledge cutoff 或 blind assessment，不能进入正式判断、计划遵守或纪律评分。
- 长桥历史委托与成交默认同步最近 180 天，可自动按标的和周期时间闭包订单与逐笔成交，也可由用户明确选择；周期外、未关联的账户订单不会悄悄进入样本。最近财报候选只显示过去 240 天内最多 3 次，并使用本机缓存与后台刷新减少等待。
- 同步历史时会对缺失父订单的成交按唯一 `order_id` 做有上限、只读的 `order_detail` 回补；仍无法核验方向和币种的股票成交会保留原始审计字段，但界面显示“成交价未核验”，并从确定性 P&L 中排除。系统不会根据 `.US` 或价格大小猜测成交方向。
- 技术复盘可使用宿主按每个节点截止时间裁切的日线证据与确定性计算结果；EMA、Fib 只是可选证据，不是硬编码主结论。单标的路径以框选的最早 Buy 成交到最晚 Sell 成交为边界，最多 3 个交易日逐日展示，跨度更长时按不重叠的 `3 / 3 / … / 余数` 交易日分段；部分卖出明确保留剩余数量，不冒充完整平仓。阶段二在可计算时提供已关联成交配对毛利、周期/基准/超额收益与日线价格 MAE/MFE；费用、起始库存或行情缺失时返回空值及原因。
- 复盘页维护独立的本机加密、只追加组合快照账本：支持版本化的常规收盘重估、成交后观察和手动观察。应用运行时每 15 分钟核验，唤醒后补检；按交易所当日实际收盘时间（包括提前收盘日）执行捕获窗口，每个美股交易日最多写入一个 v2 常规收盘重估，并保存估值版本、最早/最晚 `quoteAsOf`。已确认成功后不再联网重估；被动盘后价格变化不会自动保存，也不会覆盖该记录，只有手动或成交后观察会另行追加。由于持仓数量和现金是在收盘后抓取，常规收盘重估明确为 `partial`，不能作为确定性收益端点，也不冒充完整券商收盘净值。旧版 EOD 保留为不可变历史，但不会阻止新版重估。界面显示最后尝试、最后成功和最近错误；窗口内失败可重试，超窗保留缺口。应用关闭期间不会运行，也不会用当前持仓补造错过日期的历史快照；后台驻留与登录启动须由用户明确开启。月度复盘只使用真实存在且质量合格的起点/终点快照；没有历史快照时继续做动作与流程审计，但不会把当前持仓倒填为历史仓位，也不会把未核对现金流、费用和税费的净资产变化称为周期收益。QQQ 与持仓日线另行加密缓存，离线或超时时必须带缓存时间与覆盖降级说明。
- Agent 可把复盘结论整理为“可证伪假设 + 样本口径 + 指标/窗口 + 候选规则”的一体化草案。验证中心的主路径为“AI 生成草案 → 用户编辑并确认开始观察 → 系统寻找后续已完成复盘 → 用户确认纳入样本 → 系统更新胜率、赔率与期望 R → 达到门槛后由用户选择继续观察、创建 v2、暂行采用或退役”。候选由主进程按当前证据生成并区分前向、跨边界和历史校准；假设来源只作基线。观察可随时“停止并归档”，从活动列表移除但不删除来源、样本和状态历史。证据重选会冻结旧草案、协议和规则，重复确认保持幂等；正式晋级取决于当前协议的确定性评估、合格样本与人工决策，未支持或未达到的条件在界面逐项说明，模型不能自动晋级。

## Codex 持久项目

- 默认工作区为 `trading-agent-workspace/`，线程 ID 加密保存在应用状态中，重启后通过 App Server `thread/resume` 继续。
- Codex 正常继承本机配置、全局/项目 Skills、MCP、Apps、项目规则、网页和文件工具，不再使用临时或只读推理会话。
- 每轮按分析范围提供结构化上下文：单标的只有目标与组合摘要，全组合才包含完整持仓；账户号和 OAuth 凭证不会进入模型上下文。
- 驾驶舱可管理多个独立持久 thread，并在同一 App Server 连接内按 thread 并发运行；新会话不会继承其他会话的聊天内容，完成事件与取消也按 thread 隔离。
- UI 只拉取会话元数据并在本地筛选；点击会话后通过一次 `thread/resume` 同时取得最近 30 个摘要 turn，不再扫描所有对话或把摘要转成 `/history`。若正文水合超时，会立即打开同一 thread 并使用加密本地索引兜底。Agent 显式查询过去讨论时仍只允许最近 30 天。
- 这些记录是本机 `source=appServer` 的 Codex thread，不是 ChatGPT 网页对话，因此不会出现在 ChatGPT/GPT 网页历史侧栏；驾驶舱自己的“本机对话”列表才是可靠入口。
- 长桥本身仍是查询白名单，最终交易由用户在券商端手动确认。
