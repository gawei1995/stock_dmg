## 0.23.0 发布记录

## 数据真相与账户隔离

- 缺少券商成本时不再把成本写成 `0`，也不会制造整段市值等于盈利的假象；市值和组合权重仍可显示，成本与盈亏明确标为“未提供”。仅含 USD 的组合不再因为无须使用的汇率服务失败而降级。
- 复盘默认排除未成交、取消、拒绝和不可核验订单。只有父订单而没有成交明细的股票记录会用交易日未复权 K 线核验；明显异常价格只进入审计区，不再成为买卖证据。
- 复盘案例、周期和组合快照都绑定不可逆的账户作用域。切换长桥账户后不会混用旧账户数据；旧版未绑定记录只保留审计用途，需要重新选择券商记录。
- 长桥授权现在有独立代际边界。清授权或切换账户后，迟到的旧请求不能再写持仓缓存、激活账户作用域、刷新界面、生成快照或返回旧账户的 Agent 结论；重授权等待有 30 秒硬上限，不会无限卡住。

## 技术证据与复盘

- 技术证据现在明确分为 Tier-A 批量雷达与 Tier-B 单标的深度分析。两层只使用已完成 K 线，并以同一个精确已完成日线 cutoff 对齐；缺失保持 N/A，绝不前向填补。
- Tier-B 的行业 ETF 和同行联动需要用户确认。同行比较如启用，必须是 2–5 个同行；模型建议不等于确认。AVWAP 必须引用本轮已完成价格序列中的显式锚点和理由，并由宿主复算。
- 没有来源、时间和可核验输入的期权链、定位或催化剂事实均为 N/A。未平仓量不会被用于推断 dealer gamma。
- 历史技术样本和人工观察只是校准/发现材料，不会推进正式验证。只有协议冻结在入场前、引用当前证据版本且具有可核验净 R 的前向样本才进入正式计数；达到门槛后仍由用户决定继续观察、建立 v2 或退役。
- 验证协议新增机器可读比较符和数值门槛。正式评估只由宿主从至少 `max(20, 声明样本数)` 个已核验前向唯一案例计算，支持累计净 R、平均期望 R、胜率百分比和赔率；观察值、通过结论及哈希都绑定冻结协议与样本集合，模型和前端不能自行声明通过。旧协议缺少机器门槛时保持锁定，可显式创建 v2。
- 财报事件不再由系统替用户自动选中；案例与周期切换分别保存草稿。刷新失败时保留上次成功快照并显式提示，不再清空页面造成“数据消失”。
- 复盘快照只允许最新请求提交，慢的旧请求不会把页面回退；最近财报预取失败后可以直接重试，并保留已有候选而不是永久短路。
- 当前门槛先要求至少 20 个唯一周期的合资格前向样本并由人工复核。重叠持有窗口和同一事件拆分样本的独立性尚未建模，因此没有机器可计算成功标准的规则继续 fail closed。`planned R`、`stress R` 与核验后的 `realized R` 分别记录，不互相替代。

## 复盘上下文与数值可信度

- 每轮 Codex 复盘证据现在生成确定性 manifest：记录每个块的 SHA-256、整包 hash、字符/UTF-8 字节/块数、交付状态和声明省略。超过 96,000 字符、384,000 UTF-8 字节或 128 块会在发送前明确拒绝，不再静默截断。
- 结果卡新增 Evidence Passport，直接显示本轮证据是否完整、块数、字节、声明省略、bundle 短码和实际请求的 Skills。上下文超限、协议不兼容、缺少复盘 Skill、复盘线程串线和盲态越权属于不可重试错误，界面会立即停止，不再持续转圈等待恢复。
- 复盘线程绑定协议、周期/案例、阶段、证据 revision、回顾版本和输入快照 hash；重新打开会话仍以持久绑定为准。同一线程不能从盲态悄悄切换到结果阶段，也不能混入更新后的证据版本。
- 阶段一盲态复盘禁止近期对话查询；外部 MCP/Web/命令工具一旦出现于启动事件、完成事件或断线后的持久结果回收中，宿主都会丢弃本轮并永久隔离该线程。迟到审批同步拒绝，已有历史的普通对话不能改绑为盲态复盘。多节点盲态仍在一个模型请求内时会明确降级为逻辑隔离，不进入正式盲评统计。
- 复盘 Skill 成为必需协议，缺少时 fail closed；两个复盘 Skill 已随应用打包并在首次运行时补入项目工作区，不覆盖用户已有版本。普通复盘只自动挂载对应复盘 Skill，不再同时加载无关的叙事/技术 Skill。
- 胜率、期望 R、赔率、Profit Factor、尾部亏损等由宿主从已核验且未删失的唯一决策包计算，模型只解释。长验证台账保留完整宿主统计，原始测试行最多交付 36 条首尾样本并在 manifest 声明省略，以减少长表对模型判断的干扰。
- `null`、空值、布尔值和未知时间戳不再被数值转换为 `0` 或 `1`。该约束覆盖组合快照、候选仓位、成交数量/价格、FIFO 顺序及 OHLC。期权成交必须携带一致的真实合约乘数；缺失或冲突时 P&L、路径和 R 计算保持不可用。界面的净 R、MAE/MFE 与相关指标统一显示明确的 `R` 单位。
- 大证据轮次会在开始前按当前模型上下文和输出预留主动压缩；预计超过安全区且压缩失败时明确拒绝。盲态冻结结论保留原文 hash、交付长度和截断状态，结果复盘只有在 `truncated=false` 时才允许把它当作完整原文引用。
- 盲态节点只接收截至自身 `knowledgeCutoffAt` 已明确引入的标的、券商事实和技术快照；真实运行时间、后续长桥同步时间及工作区更新时间不会进入盲态投影。时间线券商事实只在首次可知节点交付一次，避免重复 token 与双重计数。

## Agent 运行可靠性

- Agent 不再因分析耗时较长而被本地超时终止。系统持续从 Codex 持久线程回收结果；只有连续 4 次终态传输失败才停止转圈，并给出明确可重试状态。已完整生成的最终答案会优先安全交付。
- App Server 重连使用代际隔离，旧进程的迟到回调不会覆盖新任务。不同对话仍共享一套 Codex harness，但可并行独立运行；旧 operation 的迟到结果不会覆盖同一对话中的新问题。
- 近 30 天历史改为本地索引与元数据优先，最多补取 20 个候选并受 8 秒整体预算约束；部分结果会明确标注，不再为查询历史扫描大量完整会话。
- Skills、MCP 与 Apps 分别维护新鲜度和错误状态；单项挂起不会阻塞其余能力，更新事件也不会在刷新期间丢失。长桥写操作仍由宿主拒绝。
- Agent 流式输出只在用户仍位于底部时自动跟随；向上阅读不会再被抢回底部，并提供“跳到最新”按钮。流式正文不再放进第二层纵向滚动区。
