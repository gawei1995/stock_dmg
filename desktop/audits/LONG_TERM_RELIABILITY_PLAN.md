# 长期运行保障 · C 阶段接续清单

准备日期：2026-09-18；C1/C2已在0.24.4实现，发布验证另见实施台账。本文保留后续C3/C4计划；总进度以 `STABILITY_IMPLEMENTATION.md` 为准，不代表真实连续多日已验收。

## 已确认的接口与边界

- 收盘捕获、后台偏好、重连退避和覆盖账本已有独立模块。后台驻留/登录启动默认关闭，必须保留用户显式开关；不能为了测试偷偷开启。
- 主进程捕获流程会并行读取真实组合与行情，不能只靠纯日期函数测试证明跨天恢复可靠。受控测试应直接执行宿主流程并使用隔离 store、时钟、连接与行情替身。
- 新健康页只读检查；不触发券商、Agent、覆盖修复或快照采集。快照成功标记必须关联已核验账本中同账户/交易日的实际记录。
- 当前持久快照上限为 12,000 条 / 64 MiB，雷达为 400 批 / 96 MiB。现状是到上限拒绝新写入而不删除旧证据。健康页已显示已知计数及限额，但未测字节明确为未知；这还不是容量预警或分段账本。
- 备份 `trusted-backup-bundle.mjs` 已扩展为五个加密业务文件（含business-state.bin），使用 safeStorage 原身份解密；兼容旧v2四文件。它不是可移植灾备，设备执行开关和活动账户权威元数据不导出；索引不等于外部Codex完整transcript。

## C1 · 受控多日宿主场景（0.24.4已实现）

至少覆盖：正常收盘成功；窗口内断网再恢复；睡眠跨过截止窗口；退出后次日重启；授权 A→B→A；快照写成功而覆盖索引写失败；重复唤醒/轮询；提前收盘和夏令时。记录每个交易日的快照 ID、覆盖终态、尝试次数、账户身份和重启后结果。

验收必须同时证明：成功后不重新联网重估；盘后变化另记观察且不覆盖 EOD；超时留 gap 而非用当前账户补造历史；账户变化后旧结果不能提交。受控时钟结果与真实连续多日验收分列，模拟通过不能代替后者。

## C2 · 业务索引与凭证分离（0.24.4已实现）

原代码核对发现以下非凭证业务曾混在 `secure-state.bin`：

- `codexWorkspaceThread`、`codexWorkspaceThreadRegistry`、`codexWorkspaceRecentHistoryIndex`。
- `agentResultsByThreadV1` 及旧 `lastAgentResult` 兼容值。
- `watchPlans`、`tradingViewLastUrl`、后台快照偏好及账户作用域元数据。

先为本机备份列出“包含/排除/可重建/需原外部服务”的覆盖清单，再建立固定白名单业务索引文件；不得直接复制全部 secure state 或导出凭证。迁移应先成功提交并验证目标，保留可恢复原值；拒绝合并其他账户或任意外部 thread。恢复应用索引不等于恢复 Codex 外部完整 transcript。

备份新增业务文件时同步扩展格式/限额、只读预检、恢复槽、回滚和旧版四文件备份兼容测试；用隔离目录完成故障恢复演练。跨机器、口令加密及离机目的地属于单独产品选择，未经确认不启用。

实施调整：仅迁移前三个Codex索引、两个结果兼容键、watchPlans和tradingViewLastUrl，共七项。后台偏好与活动账户scope不属于可恢复的执行权限，保留在本机secure store。迁移receipt防旧值回流；旧行情/快照迁移也补充独立权威标记。恢复所有业务写入暂停、账户提交守卫，失败回滚并保留无法回滚的恢复副本；未知/其他工作区索引不赋予外部线程权限。未提供损坏文件导致无法启动时的一键恢复UI，仍须保留原文件进行离线受信任恢复；未实现断电跨文件事务，这两个边界保留为明确后续灾备项。

## C3 · 容量与受控封存

先提供真实字节计量及阈值提示，再设计显式封存：不可变分段、清单哈希、跨段连续性、合并查询、崩溃原子性、导出/恢复全段覆盖。不能通过调大单文件上限、滚动删除旧记录或只复制一份压缩包宣称完成。封存影响用户证据的操作应先预览并确认，失败保留原账本。

## C4 · 收益对账状态与数值语义

- 当前 `regular-close-v2` 只按收盘价格重估，数量和现金来自盘后观测，固定 partial；依然不能作为完整收益端点。
- 应逐周期记录起终库存、外部资金流、费用税费、企业行动、币种/汇率和基准覆盖的核对状态与来源时间，缺失保持缺失，不能把端点净值变化叫收益率。
- 技术/组合/复盘建立固定输入-事实-模型引用评估集，覆盖百分数/百分点、原币/USD、期权乘数与Delta、数量/金额、负现金、零与未知、复权/交易时段/完整K线、样本分母及前后信息边界。
- 模型仍自主解释技术证据，EMA/Fib不变成强制唯一策略。评估确定性运算和模型引用语义，不以文本通顺替代数值正确，也不以本地单元测试冒充真实模型运行评估。
