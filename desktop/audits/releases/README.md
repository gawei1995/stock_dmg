历史源码含 **MCP SDK 1.30.0 及已知有漏洞的传递依赖**。保留它是为了核对过去的构建，不能将原历史验证通过解释为当前安全批准，也不能用修复后的源码同版本覆盖原产物。

从仓库根目录可只读核验共享证据：

```bash
python3 desktop/audits/releases/verify-evidence.py
```

核验器使用 Python 标准库；检查整个归档恰好覆盖清单全部文件、文件字节/权限、源码及 Skill 清单树哈希、锁文件哈希和联合输入指纹。它拒绝多余文件、缺失文件、链接和不安全路径，直接读取归档内容，**不解压、不执行源码、不安装依赖、不访问运行时工作区或用户数据**。

如已另外取得可信的原 DMG/ZIP，并放在某目录的 `release/` 下，可同时核对二进制字节。例如本机原产物仍在 `desktop/release/`：

```bash
python3 desktop/audits/releases/verify-evidence.py --artifact-root desktop
```

没有提供二进制副本时，结果明确显示 DMG/ZIP **未检查**；仓库仅有其预期哈希，不能独立证明二进制下载可用或取得的二进制确与记录一致。

重新运行旧测试或重打包不属于证据核验。历史记录不证明当前安装态、真实模型、长桥/IBKR/TradingView 授权、连续交易日覆盖或用户数据迁移已经通过；它也不是签名证明，不承诺未来 DMG 逐字节重现。当前开发修复、发布和 P0 结果以根目录 `NEXT_STEPS.md` 为活动入口。
