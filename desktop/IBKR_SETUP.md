# IBKR 持仓与期权信息接入

2026-10-07：TWS 10.50 适配已进入待发布源码；没有为此单独升版、打包或替换已安装驾驶舱。下述自动查找新版应用与新账本字段兼容需下一批构建后进入安装版。

## 界面

左栏顶部为「全部账户 / 长桥 / IBKR」。两家券商各有一行净资产、现金比例、状态与独立刷新按钮；不增加第二张常驻表，不改变 TV 的大小。

全部账户以 USD 汇总已接入账户。同一市场、同一代码的股票合并市值，展开查看各券商数量和成本。跨账户多空保留毛敞口；期权合约不跨券商推断合并。购买力、保证金与可用现金不跨账户抵扣。未同步券商会令全账户总额/权重保持未知，不用部分资产冒充总资产。

本版 IBKR 支持选定一个真实账户；如果返回多个账户，需要选择。不会自动把所有子账户相加。

## 首次连接

1. 复用已安装的 **Trader Workstation 10.50**，启动并登录，不需要额外安装网页网关。待发布源码在用户与系统 Applications 标准目录查找完整 TWS 应用，优先已识别的最高数字版本；通用未标版本安装作为后备，忽略卸载器和残留目录，不再固定 10.30 路径。
2. TWS「全局配置 → API → 设置」中启用 Socket 客户端、保留只读 API，限制本机连接。实盘常用 7496、模拟盘 7497；IB Gateway 常用 4001/4002，以你的实际配置为准。[官方配置说明](https://www.interactivebrokers.com/campus/trading-lessons/installing-configuring-tws-for-the-api/)
3. 驾驶舱左栏展开「IBKR 连接设置」，选择 Trader Workstation，核对端口，点击「检查连接」，确认账户后点击「保存并同步」。应用不接收用户名、密码或验证码。
4. 如果需要备用接法，可选择 Client Portal 网页网关。自行按[官方说明](https://www.interactivebrokers.com/docs/web-api/getting-started)启动网关并在其页面登录；网关官方默认端口 5000 可能被 macOS 占用，界面提供 5001 备选，但不会擅自改网关配置。仅在确认本机网关身份后允许该端口的自签名证书。
5. 登录过期时回到 TWS/网关重新登录。程序不模拟登录、不抢占交易会话、不自动接受付费行情。TWS 账户估值可能约每 3 分钟更新；同步时间不代表逐笔行情时间。

## 期权

- 从持仓读取合约、方向、张数、成本、到期日、行权价、Call/Put、明确返回的乘数、原币市值及 USD 市值。
- 从行情端点尝试读取 Bid、Ask、Last、Delta、Gamma、Theta、Vega、该合约 IV（百分比）与 OI。
- 「实时 / 延迟 / 冻结 / 未订阅 / 未知」按 IBKR 返回状态展示。账户估值与报价单独记录；响应时间不伪装成交易所成交时间。
- 缺失数据显示「—」，乘数不默认 100，`avgCost` 按明确乘数换算单位成本，券商 `mktValue` 不再乘一次乘数。
- 请求仅限所持有合约，TWS 每轮最多补充 40 个期权合约，网页网关最多 200 个合约。TWS 使用 model Greeks，IV 从小数转百分比；未计算哨兵值、负 IV、越界 Delta 保持缺失。没有实现整条期权链浏览器。
- 实时行情受 IBKR 订阅及 brokerage session 限制。能看到账户不代表有实时期权行情。参考：[行情字段与权限状态](https://www.interactivebrokers.com/docs/web-api/api-reference/trading/trading-market-data/get-md-snapshot)、[会话层级](https://www.interactivebrokers.com/docs/web-api/authentication/sessions)、[持仓字段](https://www.interactivebrokers.com/docs/web-api/v1/endpoints/portfolio/positions)。

## Agent 和数据边界

每次发送固定当时选择的账户范围；运行过程中切换左栏不会把另一个账户混入原任务。组合分析传递所有持仓、各券商明细和期权信息，单仓分析只传目标及组合摘要。继续使用原有 Codex 会话与工具链，没有新增 harness。

IBKR 与跨券商汇总目前用于持仓展示和研究；尚未完成统一实时估值/执行仓位校验，不能作为已核验的可执行仓位。期权权利金市值不是 Delta 名义敞口，Greeks 缺失时不能推断杠杆。

**本版没有把 IBKR 历史订单、每日收盘快照接入原长桥复盘账本。** 长桥现有自动快照机制不变；IBKR 当前只加密保留最近一次成功持仓缓存，重启后明确标为缓存。不能据此声称已经有 IBKR 每日历史序列。

## 安全与验证

访问仅限本机、有限超时和频率。TWS 使用独立非零客户端 ID，只读取账户与行情，完成或失败后清理订阅与连接，不绑定手工订单。网页网关不跟随网络重定向，唯一 POST 是合约搜索。不开放下单、改单、撤单、行权或资金操作。

自动测试使用明确的模拟响应验证换算、合约乘数、分页、权限失败、缓存/账户切换及 Agent 上下文。2026-09-17 已实测本机 TWS 10.30：返回真实 QQQ 8 股，与官方 IBKR 连接一致；独立只读查询 QQQ 期权成功取得实时 Bid/Ask 与 model IV/Delta/Gamma/Theta/Vega。真实账户当时未持有期权，因此“所持期权卡片”的显示与换算使用模拟响应验证，不能把查询的候选期权当成真实持仓。
